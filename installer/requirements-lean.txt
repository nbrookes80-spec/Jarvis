# Lean runtime requirements for Jarvis + Claude agent integration.
#
# Derived from installer/requirements.txt. Jarvis's PluginManager swallows
# ImportError and skips the affected plugin (jarviscli/PluginManager.py:21-31),
# so omitting a dependency disables only the plugins that import it. Nothing
# else breaks.
#
# Omitted from the full set, and what you lose:
#   Image                   -> pulls Django as a transitive dep; pillow below covers PIL
#   pydoc-markdown          -> docs tooling only (pulls black, yapf, docspec, watchdog)
#   flake8, mock            -> lint/test tooling, not runtime
#   pyaudio                 -> microphone input for `music_recognition`; it
#                              compiles against portaudio19-dev, and without that
#                              apt package it would fail this whole install
#
# To restore any of them: pip install <name> into the same venv.

# --- Core framework ---
# pluginmanager 0.4.1 imports pkg_resources, which setuptools removed in 82.0.0.

# --- Speech and audio ---
# playsound is deliberately absent. Upstream requires it, but nothing in the
# repository imports it, and on Python >= 3.12 upstream points at
# github.com/taconi/playsound, which no longer exists -- that dead URL is what
# breaks `pip install -r installer/requirements.txt` on Ubuntu 24.04 / Zorin 18.
# The audio path that is actually used is gtts + pyttsx3 (see
# jarviscli/utilities/voice.py).
gtts
pyttsx3 == 2.71; sys_platform != 'darwin'
